# AutoCare Dashboard

A full-stack vehicle maintenance management system with real-time booking, payment processing, and maintenance scheduling.

**Technology Stack:**
- **Frontend:** React 18 + TypeScript + Vite + TailwindCSS
- **Backend:** Spring Boot + Java 17 + File-based persistence
- **Ports:** Backend (3000), Frontend (5173)

## Quick Start

### For Windows Users
👉 **[Follow the detailed Windows Setup Guide](./SETUP_WINDOWS.md)**

### For Mac/Linux Users

**Prerequisites:**
- Java 17+
- Maven 3.8+
- Node.js 16+

**Setup:**

1. **Start Backend:**
   ```bash
   cd backend
   mvn spring-boot:run
   ```
   Backend runs on: `http://localhost:3000`

2. **In another terminal, start Frontend:**
   ```bash
   npm install
   npm run dev
   ```
   Frontend runs on: `http://localhost:5173`

3. **Open in Browser:**
   ```
   http://localhost:5173
   ```
